# Story 1.4: Shared Blade Components Library

## Status

Done

## Story

**As a** developer,
**I want** reusable Blade components for forms, tables, modals, and UI elements,
**so that** all feature pages have consistent markup and accessibility.

## Acceptance Criteria

1. Form components: `<x-forms.input>`, `<x-forms.select>`, `<x-forms.textarea>`, `<x-forms.date-input>`, `<x-forms.form-card>`, `<x-forms.form-group>`, `<x-forms.form-row>`, `<x-forms.submit-button>`
2. Table components: `<x-tables.data-table>`, `<x-tables.pagination>`
3. Modal components: `<x-modals.modal>`, `<x-modals.confirm-delete>`
4. UI components: `<x-ui.stat-card>`, `<x-ui.progress-card>`, `<x-ui.empty-state>`, `<x-ui.flash>`, `<x-ui.timeline>`, `<x-ui.chart>`
5. `<x-layout.page-header>`, `<x-layout.section>`
6. `<x-premium-gate>` component for upgrade prompts
7. All form components support `old()` value restoration and `@error` display
8. All components include WCAG AA ARIA attributes per coding standards
9. SCSS component stylesheets: `_buttons.scss`, `_cards.scss`, `_forms.scss`, `_tables.scss`, `_modals.scss`, `_pagination.scss`, `_timeline.scss`, `_flash.scss`, `_badges.scss`

**Integration Verification:**

- IV1: Form component renders error state with `aria-invalid` and `aria-describedby`
- IV2: Modal loads into `#modal-container` with `role="dialog"` and `aria-modal="true"`
- IV3: Flash message auto-dismisses with `role="alert"`

### Form Components — Detailed Markup

**`<x-forms.input>`** (architecture spec — exact implementation):

```blade
{{-- resources/views/components/forms/input.blade.php --}}
@props([
    'name',
    'label' => null,
    'type' => 'text',
    'value' => '',
    'required' => false,
    'placeholder' => '',
])

<div class="form-group @error($name) form-group--error @enderror">
    @if($label)
        <label for="{{ $name }}" class="form-label">
            {{ $label }}
            @if($required)<span class="form-label__required" aria-hidden="true">*</span>@endif
        </label>
    @endif

    <input
        type="{{ $type }}"
        id="{{ $name }}"
        name="{{ $name }}"
        value="{{ old($name, $value) }}"
        placeholder="{{ $placeholder }}"
        {{ $required ? 'required' : '' }}
        @error($name) aria-invalid="true" aria-describedby="{{ $name }}-error" @enderror
        {{ $attributes->merge(['class' => 'form-input']) }}
    >

    @error($name)
        <p class="form-error" id="{{ $name }}-error" role="alert">{{ $message }}</p>
    @enderror
</div>
```

[Source: architecture/frontend-architecture.md]

**`<x-forms.select>`** — follow the same error/ARIA pattern as input:

```blade
{{-- resources/views/components/forms/select.blade.php --}}
@props([
    'name',
    'label' => null,
    'options' => [],
    'value' => '',
    'required' => false,
    'placeholder' => '-- Select --',
])

<div class="form-group @error($name) form-group--error @enderror">
    @if($label)
        <label for="{{ $name }}" class="form-label">
            {{ $label }}
            @if($required)<span class="form-label__required" aria-hidden="true">*</span>@endif
        </label>
    @endif

    <select
        id="{{ $name }}"
        name="{{ $name }}"
        {{ $required ? 'required' : '' }}
        @error($name) aria-invalid="true" aria-describedby="{{ $name }}-error" @enderror
        {{ $attributes->merge(['class' => 'form-select']) }}
    >
        @if($placeholder)
            <option value="">{{ $placeholder }}</option>
        @endif
        @foreach($options as $optValue => $optLabel)
            <option value="{{ $optValue }}" {{ old($name, $value) == $optValue ? 'selected' : '' }}>
                {{ $optLabel }}
            </option>
        @endforeach
    </select>

    @error($name)
        <p class="form-error" id="{{ $name }}-error" role="alert">{{ $message }}</p>
    @enderror
</div>
```

```blade
    'subtitle' => null,
    'action',
    'method' => 'POST',
])

<div class="form-card">
    @if($title)
        <div class="form-card__header">
```

### Table Components — Detailed Markup

**`<x-tables.data-table>`**:

```blade
@props([
    'headers' => [],
    'striped' => true,
])

<div class="data-table-wrapper">
    <table class="data-table {{ $striped ? 'data-table--striped' : '' }}">
        <thead class="data-table__head">
            <tr>
                @foreach($headers as $header)
                    <th scope="col" class="data-table__header">{{ $header }}</th>
                @endforeach
            </tr>
        </thead>
        <tbody class="data-table__body">
            {{ $slot }}
        </tbody>
    </table>
</div>
```

Usage pattern: caller renders `<tr>` rows in the slot. Sortable columns can be enhanced later with `hx-get` sort params.

**`<x-tables.pagination>`**:

```blade
@props(['paginator'])

@if($paginator->hasPages())
    <nav class="pagination" aria-label="Pagination">
        {{ $paginator->links() }}
    </nav>
@endif
```

Override the default Laravel pagination view or use `$paginator->links('components.tables.pagination-links')` with a custom partial that uses BEM classes. The custom view should add `hx-get`, `hx-target`, `hx-swap` attributes for HTMX pagination.

### Modal Components — Detailed Markup

**`<x-modals.modal>`**:

```blade
@props([
    'id' => 'main-modal',
    'title',
    'size' => 'md',
    'closeable' => true,
])

<div id="{{ $id }}" class="modal modal--{{ $size }}" role="dialog" aria-modal="true" aria-labelledby="{{ $id }}-title"
     x-data="{ close() { document.getElementById('modal-container').innerHTML = ''; } }"
     @keydown.escape.window="close()">
    <div class="modal__overlay" @click="close()"></div>
    <div class="modal__content">
        <div class="modal__header">
            <h2 id="{{ $id }}-title" class="modal__title">{{ $title }}</h2>
            @if($closeable)
                <button @click="close()" class="modal__close" aria-label="Close">&times;</button>
            @endif
        </div>
        <div class="modal__body">
            {{ $slot }}
        </div>
    </div>
</div>
```

**HTMX modal loading pattern:** A trigger button uses `hx-get` to fetch a partial that returns the `<x-modals.modal>` component with form content. The response loads into `#modal-container`. On form submit success, the controller returns `HX-Trigger: closeModal` header, which the `app.js` listener clears `#modal-container`.

**`<x-modals.confirm-delete>`**:

```blade
        <button hx-delete="{{ $action }}"
                hx-target="closest tr"

</x-modals.modal>
```

### HTMX Integration Patterns

**Modal loading (used by feature controllers in later stories):**
1. Trigger button: `<button hx-get="/app/eggs/create" hx-target="#modal-container">Add Entry</button>`
2. Controller returns: `view('eggs.partials.create-form')` which wraps content in `<x-modals.modal>`
3. HTMX loads response into `#modal-container`
4. On form submit success: controller returns `HX-Trigger: closeModal` header
5. `app.js` listener clears `#modal-container`

**Pagination swap:**
1. Pagination links have: `hx-get="/app/eggs?page=2" hx-target="#table-container" hx-swap="innerHTML"`
2. Controller detects HTMX request, returns table partial only
3. HTMX swaps table content without full page reload

**Form validation (422):**
1. `app.js` handles 422 status with `htmx:beforeSwap` — allows swap even on error
2. Controller returns form partial with `@error` messages populated
3. HTMX re-renders form with validation errors visible

### Accessibility Requirements Summary

| Component Type | Required ARIA |
|---|---|
| Forms | `aria-invalid="true"` + `aria-describedby="{name}-error"` on error; `role="alert"` on error message; `aria-hidden="true"` on decorative elements |
| Modals | `role="dialog"` + `aria-modal="true"` + `aria-labelledby="{id}-title"`; Escape closes; focus trap |
| Tables | `<th scope="col">`; `aria-sort` on sortable columns; `aria-label` on icon-only buttons |
| Flash | `role="alert"` + `aria-live="polite"` (success/warning) / `"assertive"` (error) |
| Empty states | `role="status"` |
| Charts | `aria-label` describing chart purpose |
| Progress | `role="progressbar"` + `aria-valuenow` + `aria-valuemin` + `aria-valuemax` |

### Coding Standards Reminders

- **Blade components:** dot-namespaced — `<x-forms.input>`

- **No raw HTML:** Always `{{ }}`, never `{!! !!}`
- **Component props:** Use `@props()` with sensible defaults
- **Attribute forwarding:** Use `$attributes->merge(['class' => '...'])` for extensibility
