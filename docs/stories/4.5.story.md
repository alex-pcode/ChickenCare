### Sale-Customer FK Behaviour

The sales table uses `ON DELETE SET NULL` for `fk_sales_customer`. This means:
- **Hard-deleting** a customer sets `sale.customer_id = NULL` in existing sales
- **Soft-deactivating** (4.3's `is_active = false`) does NOT affect `customer_id` — sales retain the FK link
- Tests in Task 4 validate both scenarios. The `withDefault` on `Sale::customer()` ensures the view handles both null and deactivated customers gracefully.
