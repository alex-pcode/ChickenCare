- IV1: Register -> login -> logout cycle works end to end

### User Migration

Create migration `add_tier_and_admin_to_users_table`:

```php
Schema::table('users', function (Blueprint $table) {
    $table->enum('tier', ['free', 'premium'])->default('free')->after('remember_token');
    $table->boolean('is_admin')->default(false)->after('tier');
});
```

### User Model Updates

```php
// app/Models/User.php
protected $fillable = ['name', 'email', 'password', 'tier', 'is_admin'];

protected $casts = [
    'email_verified_at' => 'datetime',
    'password' => 'hashed',
    'is_admin' => 'boolean',
];

public function isPremium(): bool
{
    return $this->tier === 'premium' || $this->is_admin;
}

public function isFree(): bool
{
    return $this->tier === 'free' && !$this->is_admin;
}
```

Models are thin: `$fillable`, `$casts`, relationships, scopes only. Do NOT add other relationship methods yet — those come in later stories.

### User Factory States

```php
{

}
```

### Breeze View Restyling

Replace Tailwind utility classes with BEM classes. Auth views should use:
- `.auth-form` — form wrapper
- `.auth-form__title` — page heading
- `.auth-form__field` — form group wrapper
- `.auth-form__actions` — button/link area

- Standard `<input>`, `<label>`, `<button>` elements with `.form-input`, `.form-label`, `.btn`, `.btn--primary` classes

**Accessibility (WCAG 2.1 AA):**
- `aria-invalid="true"` + `aria-describedby` on fields with validation errors
- `role="alert"` on error messages
- `aria-hidden="true"` on decorative elements

### Coding Standards Reminders

- **Validation in Form Requests only** — no `$request->validate()` in controllers (Breeze defaults may use inline validation; leave Breeze's default Form Requests as-is)
- **No raw HTML output** — always `{{ }}`, never `{!! !!}`
- **SCSS BEM naming** — `.block__element--modifier`
- **Test method naming** — `snake_case` with `test_` prefix
- **Blade views** — kebab-case filenames
